# Keyboard Shortcuts

## File

| Shortcut | Action |
|---|---|
| `Ctrl+S` | Save |
| `Ctrl+Shift+S` | Save As |
| `Ctrl+N` | New .flowscript file |

## Edit

| Shortcut | Action |
|---|---|
| `Ctrl+Z` | Undo |
| `Ctrl+Y` | Redo |
| `Ctrl+C` | Copy selected node |
| `Ctrl+V` | Paste node |
| `Del` | Delete selected node(s) or edge(s) |

## Canvas

| Shortcut | Action |
|---|---|
| Scroll wheel | Zoom in / out |
| Click + drag (empty canvas) | Pan |
| Double-click (group node) | Enter node |
| `Escape` | Exit nested node / close modal / clear FlowBar |

## FlowBar

| Shortcut | Action |
|---|---|
| `Enter` | Submit command |
| `↑` | Recall last command |
| `Escape` | Dismiss FlowBar |
| `↑` / `↓` | Navigate autocomplete suggestions |
| `Tab` or `Enter` | Accept autocomplete suggestion |

## Code Mode

| Shortcut | Action |
|---|---|
| `Ctrl+Space` | Trigger autocomplete (keywords, node names) |
| `Ctrl+Z` / `Ctrl+Y` | Undo / Redo |

## Toolbar Buttons

The toolbar in the top-left also has buttons for:

- **+ Node** — add a new action node
- **+ Note** — add a note
- **+ Property** — add a property to the current nested node (nested view only)
- **↑ Up** — exit the current nested node (nested view only)
- **Undo / Redo** — in the title bar

## FlowBar Commands (quick reference)

Type any of these in the FlowBar and press Enter. See [FlowBar Commands](flowbar-commands.md) for the full reference.

| Command | What it does |
|---|---|
| `addNode(name)` | Create a node |
| `deleteNode(name)` | Delete a node |
| `renameNode(name): newName` | Rename a node |
| `copyNode(name)` | Duplicate a node |
| `zoom(all)` | Fit all nodes in view |
| `zoom(name)` | Jump to a node |
| `addShape(box\|circle)` | Add a shape |
| `newTheme(name)` | Open theme creator |
| `showHelp` | Open shortcuts panel |
